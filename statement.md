# Problem Statement

Sharing the expenses of a flat can become difficult when rent, food, and electricity costs have to be divided among several people. Manually calculating these expenses can take time and may lead to calculation mistakes.

The **Rent Calculator** project provides a simple Python-based solution. It collects the flat rent, food expense, electricity units consumed, electricity charge per unit, and number of people living in the flat. The program calculates the electricity bill and then calculates the amount that each person needs to pay.

## Scope of the Project

The project focuses on calculating and equally dividing three main shared expenses:

- Flat rent
- Food expenses
- Electricity expenses

The current version is a simple command-line Python program. It accepts values from the user, performs the required calculations, and displays the amount payable by each person.

The project does not currently include a database, graphical user interface, online payment system, or user account management.

## Target Users

The project is intended for:

- Students sharing a hostel or rented flat.
- Roommates sharing household expenses.
- People who want a quick way to divide common flat expenses.

## High-Level Features

1. **Expense Input**
   - Enter flat rent.
   - Enter food expenses.
   - Enter electricity units.
   - Enter electricity charge per unit.
   - Enter number of people.

2. **Expense Calculation**
   - Calculate the total electricity bill.
   - Add rent, food, and electricity expenses.
   - Divide the total expense among the residents.

3. **Result Display**
   - Display the amount each person needs to pay.

## Objective

The main objective is to develop a simple and understandable Python program that applies basic programming concepts to a practical real-world expense-sharing problem.
